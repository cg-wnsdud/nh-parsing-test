## 4. 농협 협의 상태 (참고)

### 우리가 발신하고 농협이 이의 달지 않은 것 (= 묵인, 지시가 아님)

> **정정 이력**: 인수인계 문서 최초 작성 때 아래 5개를 "농협 회신 요지"로 적었는데 **틀렸다.**
> 이 5개는 우리가 회의 후 농협에 **발신한 메일의 "회의 주요 결정사항"** 이다. 농협 회신에는
> 이 5개 언급이 없다 — 우리 메일이 "수정하실 부분 있으면 말씀 부탁"이라 했고 정정이 없었으므로
> **우리가 정리한 구조에 이의를 달지 않은 상태**로 읽어야 한다.

- (연동 아키텍처) 커스텀 파서는 진입점 역할만, 실제 문서 처리는 별도 에이전트 서비스
- (벡터 적재) DAP 날리지 레이크 파이프라인 경유 원칙 준수
- (실행 환경) Python 3.11 및 DAP 베이스 이미지 기준으로 의존성 고정
- (패키지 반입) 신규·버전 상이 라이브러리는 리스트로 전달 → 농협이 베이스 이미지 재빌드
- (웹 배포) 프론트엔드(WAS)는 컨테이너 이미지 형태로 제공

### 우리가 요청한 자료 5건 → 농협 회신

| ② DAP 베이스 이미지 Python 버전 + 라이브러리 리스트 | 파일 첨부 | **절반만** — `2.Package.txt` 는 pip list 285개뿐, **파이썬 버전 표기 없음** |

### 우리가 약속한 산출물 3건 (아직 안 보냄)

```
1. 아키텍처 설계안 (진입점 + 에이전트 서비스 + 웹 컨테이너)  ← 초안 상태
2. 필요 패키지 리스트                                    ← 반입 목록 작업 결과물
```
